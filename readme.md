# Object Detection and Tracking

## Task 4 - CodeAlpha Internship

This project demonstrates real-time object detection and tracking using a webcam.

## Features

* Real-time webcam video input
* Pre-trained COCO-SSD object detection model
* Detection of objects in video frames
* Bounding boxes around detected objects
* Object labels
* Tracking IDs for detected objects
* Runs directly in a web browser

## Technologies Used

* HTML
* CSS
* JavaScript
* TensorFlow.js
* COCO-SSD
* Webcam API

## How to Run

1. Download or clone this repository.
2. Open `index.html` using a local server such as VS Code Live Server.
3. Allow camera permission when requested.
4. Click **Start Camera**.
5. The application will detect objects and display bounding boxes and tracking IDs.

The application displays detected objects in real time with:

* Object name
* Bounding box

